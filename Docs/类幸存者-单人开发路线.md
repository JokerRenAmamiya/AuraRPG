# 类幸存者（Vampire Survivors 式）单人 UE 开发路线

> 目标：一名开发者用 UE 5.6 + 现成/AI 美术资产，几周内做出可上架（或先上 itch.io 试水）的小体量游戏。
> 前提：已掌握 Aura 课程里的 Enhanced Input、GameplayAbilitySystem（GAS）、AttributeSet、Blueprint 基础。

---

## 一、一句话定位

**俯视角角色自动攻击 → 海量敌人涌来 → 击杀掉经验 → 升级三选一 → 撑到时间出 Boss。**

---

## 二、核心玩法循环

```
移动 → 自动攻击 → 击杀敌人 → 掉落经验 → 拾取升级 → 三选一强化 → 变强 → 应对更强敌人/波次 → 最终 Boss → 结算
```

**第一版砍掉**：剧情、多地图切换、复杂 Boss 机制、联机、局外养成（金币解锁永久强化可做二阶段）。
目标先做「一张地图打 10 分钟」的完整闭环。

---

## 三、系统清单

| 系统 | 说明 | 优先级 |
|---|---|---|
| 俯视角移动 | 8 方向 / 鼠标方向，正交或俯视相机 | 必须 |
| 自动武器 | 近战范围、投射物、环绕光环 3 类起步 | 必须 |
| 敌人 AI | 朝玩家追逐，海量同屏 | 必须 |
| 经验/掉落 | 击杀掉经验球，拾取升级 | 必须 |
| 升级三选一 | 随机抽 3 个强化选项 | 必须 |
| 波次/Boss | 计时刷怪，结尾 Boss | 必须 |
| UI | 血条、经验条、升级面板、伤害数字 | 必须 |
| 局外成长 | 金币解锁永久强化 | 二阶段 |

## 四、技术路线（UE 具体实现）

### 4.1 技术选型决策

| 方案 | 适用 | 说明 |
|---|---|---|
| **轻量路线**（推荐先做） | 快速出 demo | 角色用 `Pawn`/顶层 `Character` + `Enhanced Input`；伤害用结构体 + `ApplyDamage`；武器用 `UObject`/`ActorComponent` 周期触发 |
| **GAS 路线**（复用 Aura） | 想练 GAS / 武器需要能力交互 | 每种武器做成自动触发的 `GameplayAbility`（`ActivateAbility` 里起循环 Timer 周期发射），敌人属性用 `AttributeSet`，升级用 `GameplayEffect` |

> 建议：先用轻量方案跑通闭环，武器系统确实需要「能力/冷却/增益」交互时再切 GAS。

### 4.2 关键类与结构

- **玩家**：`APawn` / `ACharacter` + `UCharacterMovementComponent`（或直接用 `FloatingPawnMovement`）+ `EnhancedInput`
- **相机**：`ACameraActor` 固定俯视，或 `SpringArmComponent` 跟随
- **武器基类**：统一接口 = 攻击频率 + 范围 + 伤害 + 目标选择，新武器只填参数
- **敌人**：轻量 `Actor` + 对象池；渲染用 `InstancedStaticMeshComponent`（ISM/HISM）
- **刷怪**：`ASpawnManager` + `DataTable` 波次表（时间 → 敌人类型 → 数量 → 位置）
- **升级三选一**：`DataTable` 管理「武器等级 → 数值」，UI 用 `UUserWidget` 三卡片

### 4.3 性能要点（核心）

- 同屏敌人几百上千，**不要**每个敌人跑完整 `Tick` + 复杂碰撞；用 ISM + 简化 `Sphere` 碰撞
- 伤害数字、经验球、投射物全部**对象池**（`TArray` 自写池或插件）
- 敌人逻辑用 `Timer` 而非 `Tick`
- 第一天就验证「1000 个敌人不卡」，再往上堆玩法

## 五、里程碑（单人约 3–5 周）

1. **第 1 周**：俯视角移动 + 1 个自动武器 + 10 个敌人追逐/被击杀
2. **第 2 周**：经验掉落 + 升级三选一 + 3~5 种武器 + 伤害数字
3. **第 3 周**：敌人类型 ×3 + 波次系统 + 最终 Boss + 死亡/重开
4. **第 4 周**：音效 + 屏幕震动/特效打磨 + 打包（可先上 itch.io 试水）

## 六、资产搭配清单（现成 + AI）

| 类别 | 现成素材 | AI 能帮 |
|---|---|---|
| 玩家/敌人角色 | Mixamo 角色（免费绑定+动作）、Kenney 低模、Synty low-poly 包 | 2D 怪物贴图、概念设定图 |
| 俯视地图 | 一张 tileable 地面 + 障碍物；Megascans 地面材质 | 地面/墙面 PBR 贴图 |
| 武器特效 | Fab 免费 VFX 包、Niagara 官方示例 | 特效概念图（做参考） |
| 图标/UI | Kenney UI 包、Fab 免费 UI Kit | **AI 出技能图标**（最稳用途） |
| 音效/音乐 | freesound、Kenney audio、itch.io 免费包 | Suno/Udio 做 BGM、ElevenLabs 配音 |
| 伤害数字字体 | 免费像素字体 | 风格化 UI 字效参考 |

**资产原则**：风格统一（低多边形/像素二选一）＞ 单个资产精良。AI 出图没问题，但 3D 角色建模 + 绑定 + 动画交给 Mixamo / Synty 现成包更稳。

---

## 七、常见坑

1. **同屏敌人数量是生死线**：先做对象池 + 简化，再堆玩法
2. **别一上来就上 GAS 全家桶**：轻量方案先跑通闭环
3. **自动武器抽象成统一接口**：加新武器只填参数
4. **升级数值做表**：用 DataTable，别硬编码，方便调平衡
